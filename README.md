# Ocean Enclave Journey

Build the web app — set up `/`, `/verify`, and `/tide-pool` with the ocean depth descent and placeholder media. and create full fledged frontend.

Follow the complete specifications, copy, color tokens, and layout from the attached brand document:
- Visual identity: dark theme with ocean descent gradient (shallows #0E2A3F to abyss #050B14), deep #0A1626, current #12233A, foam #E8EEF5, mist #8A9BB0, pearl #F6F1EA, nacre gradient, kelp, tide, coral. Typography: Fraunces, Instrument Sans, JetBrains Mono.
- Home page (/): ocean depth descent with depth markers, caustic ripples/floating marine particles, live status strip, dev wallet explanation, 4-step enclave process, shell rules, interactive timeline of TEEs/enclaves (-200m), token info card, and FAQ accordion.
- Verify page (/verify): interactive verification console with the 5 checks running live/simulated against hardware attestation and chain state with sonar-ping visual indicators.
- Tide Pool page (/tide-pool): interactive mascot dress-up / inspection area for Perly with gear (brass helmet, sailor cap, monocle, lantern, seaweed scarf, DO NOT OPEN sticker).
- Global navigation, mobile responsiveness, demo banner, and footer.
